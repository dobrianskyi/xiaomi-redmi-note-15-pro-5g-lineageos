# Updates

## 2026-11-07 — Android 16 refresh

The existing Android16 release has been refreshed in place with a new 24-patch
minimal-GApps image. It includes native/JNI/Java lapis vibration discovery,
four-digit PIN auto-confirm, the media mute button and stream/group mute
persistence across reboot. Earlier device fixes and Bluetooth defaults remain
integrated. Compilation and offline compatibility/privacy checks passed; no
phone boot or hardware result is claimed for these exact Android16 bytes.
[Release](https://github.com/dobrianskyi/xiaomi-redmi-note-15-pro-5g-lineageos/releases/tag/23.2-lapis-20260918).

Use the lineage-23.2 branch for Android16 source. Main contains Android17, whose
related vibration and reboot-mute fixes have been tested on the maintainer's phone.
